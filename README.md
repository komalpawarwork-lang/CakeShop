# 🎂 Cake Shop - React Props Project

Cake Shop is a React.js-based web application that showcases a dynamic cake store interface using component-based architecture and props. The project demonstrates how data can be passed between components to render reusable and interactive UI elements.

## 🚀 Features

- 🍰 Display multiple cake products dynamically
- 🔄 Use of props to pass data between components
- 🧩 Reusable component structure
- 🛒 Product listing with images, names, and prices
- ⚡ Fast and responsive UI
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## 💡 Project Objective

The main objective of this project is to understand and implement React props for building dynamic and reusable UI components.
